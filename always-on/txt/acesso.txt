# Como acessar a VPS por SSH e VS Code  
O agente é a sessão do Claude Code (https://claude.com/product/claude-code) que trabalha na máquina, a VPS alugada. O celular fala com ele pelo Remote Control (https://code.claude.com/docs/en/remote-control), o recurso que liga uma sessão do Claude Code ao app do Claude, sem SSH. O SSH serve ao terminal, ao VS Code (https://code.visualstudio.com/) e para abrir no seu navegador o app que roda na máquina. 

## O bloco do ~/.ssh/config 
Autorize na máquina todas as chaves de onde você vai entrar. No Windows com WSL (https://learn.microsoft.com/windows/wsl/), a chave do Windows e a do WSL são arquivos diferentes, então autorize as duas. Na máquina que já entra, mande a chave pública da outra. No WSL, a chave do Windows fica em `/mnt/c/Users/<seu-usuario-windows>/.ssh`. 

bash, na máquina que já entra
```
cat /caminho/da/outra/id_ed25519.pub | ssh agente 'cat >> ~/.ssh/authorized_keys'
```

~/.ssh/config
```
Host agente
    HostName <ip-publico>
    User voce
    IdentityFile ~/.ssh/id_ed25519
```

~/.ssh/config
```
Host host-do-agente
    HostName <ip-publico-do-host>
    User ubuntu

Host agente
    HostName 192.168.200.10
    User voce
    ProxyJump host-do-agente
```

No Windows, o arquivo é `C:\Users\voce\.ssh\config`, e é ele que o VS Code lê. No macOS e no Linux, `~/.ssh/config`. Com o bloco gravado, `ssh agente` entra direto. 

## VS Code 

- Instale a extensão Remote-SSH (https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh). Instale pelo painel de extensões do VS Code. No Windows, instale na janela do Windows, porque o `code --install-extension` chamado de dentro do WSL instala no lado WSL, e a janela do Windows não enxerga a extensão. 
- Conecte. F1, "Remote-SSH: Connect to Host", `agente`, Linux. 
- Abra uma pasta. Na primeira vez, abra a pasta pessoal, porque o repo só chega em Como organizar pastas, repos e segredos (txt/codigo.txt). A primeira conexão instala o servidor do VS Code na máquina, em cerca de 1 minuto. Quando um servidor de desenvolvimento abre uma porta lá, o VS Code encaminha a porta para o seu computador sozinho.  

## O app no seu navegador 

bash
```
ssh -L 3000:localhost:3000 agente
```

Com o túnel aberto, abra `http://localhost:3000`. O endereço continua localhost, então login e callback de OAuth funcionam sem mudar configuração. 

## Fechar a porta 22 
Este passo é opcional. O Tailscale (https://tailscale.com/) põe a máquina numa rede privada sua, e a porta 22 deixa de ficar aberta para a internet. O plano Personal é grátis para até 6 usuários. 

bash, na máquina
```
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

O `tailscale up` mostra um link. Abra o link, entre na sua conta e instale o Tailscale também no computador de onde você entra. Troque o `HostName` do `~/.ssh/config` pelo nome da máquina na rede privada, e confira que `ssh agente` entra por esse nome antes de seguir. 

bash, na máquina, só numa VPS com ufw
```
sudo ufw allow in on tailscale0 to any port 22
sudo ufw delete allow OpenSSH
```

Na Oracle (https://www.oracle.com/cloud/free/), pule o bloco acima e apague a regra da porta 22 na security list da VCN, a rede virtual da Oracle.
