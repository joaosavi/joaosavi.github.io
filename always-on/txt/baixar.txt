# Pegue qualquer arquivo da VPS, até pelo celular  
Pelo terminal, com `scp`. Pelo celular, num Artifact privado do claude.ai (https://claude.ai). 

## Pelo terminal 
No terminal do seu computador, com o bloco do `~/.ssh/config` já gravado, rode: 

bash, na sua máquina
```
scp <maquina>:~/caminho/relatorio.pdf .
```

## Pelo celular 
Sem terminal à mão, como no celular, peça à sessão do Claude Code (https://claude.com/product/claude-code) para publicar o arquivo num Artifact, uma página privada do claude.ai que só você abre, com botão de download.
